Blazor WASM Packager

Release date: 2025-11-12. Website: https://github.com/dcsoft-yyf/BlazorWASMPackager

This tool packages core resource files of a Blazor WebAssembly application into a single JavaScript file. It supports Blazor WASM 7.0/8.0/9.0/10.0. Place this HTML file at the application's published root (the parent directory of the _framework folder). After clicking the button below, the tool will:

  1. Parse the application's _framework/blazor.boot.json configuration (and include it in the package)
  2. Force-package all resources listed in boot.json (including JS files)
  3. Download those resources and GZIP them at maximum compression
  4. Optionally merge user-specified custom scripts into Merge.js and include it
  5. Generate a JavaScript file containing all resources and provide it for download
Hint: leave empty to use the default name (entryAssembly + .published.js). Make sure to include the .js extension.
Hint: enter custom JS filenames to merge; they will be combined into Merge.js and included. Leave empty to skip Merge.js generation.
